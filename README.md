# Таблетки против бактерий (Pills vs Bacteria)

Казуальная HTML5-игра для Яндекс Игр. Бактерии медленно опускаются сверху, а вы стреляете по ним
таблетками: тап или клик — таблетка летит вверх. Бактерия дошла до красной линии внизу — проигрыш.
Каждые 30 секунд игра становится быстрее.

Полное описание проекта, структура и правила — в [CLAUDE.md](CLAUDE.md).

## Как поиграть

Нужен установленный [Node.js](https://nodejs.org) (версия 20 или новее). В терминале:

```
git clone -b claude/pills-bacteria-game-plan-1frwn6 https://github.com/Aurinox-eng/1.git
cd 1
npm install
npm run dev
```

Откройте в браузере адрес **http://localhost:5173**. Чтобы поиграть с телефона, подключите его к той же
Wi-Fi сети и откройте адрес `Network:`, который напечатает команда.

Управление: тап (телефон) или клик мышью (компьютер) в любом месте экрана — выстрел. Можно стрелять двумя
пальцами.

## Игра по постоянной ссылке (GitHub Pages)

Ссылка: **https://aurinox-eng.github.io/1/** — её можно открыть с любого телефона или компьютера.

Игра выкладывается сама: при каждом обновлении ветки `main` GitHub собирает игру и обновляет ссылку
(1–2 минуты; если на телефоне видна старая версия — обновите страницу). Какая версия сейчас выложена, видно
по адресу https://aurinox-eng.github.io/1/version.txt. Ход сборки — вкладка **Actions** в репозитории.

**Однократная настройка (делается в GitHub, я сделать её не могу):**
1. Репозиторий → **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. GitHub Pages не работает на бесплатном тарифе для закрытых (private) репозиториев. Сейчас репозиторий
   закрытый, поэтому нужно одно из двух: сделать его публичным (Settings → General → Danger Zone → Change
   visibility; станет виден весь код и история) или подключить платный тариф GitHub Pro.
   Сайт на Pages открыт всем, кто знает ссылку, даже если репозиторий закрытый.
3. Игра появится по ссылке после первого обновления `main` — пока в `main` только исходный README, надо
   влить туда рабочую ветку (Pull request → Merge). Либо запустить сборку вручную:
   Actions → «Опубликовать игру» → Run workflow (сработает, когда в `main` будет игра).

## Как поменять сложность

Все числа баланса лежат в одном файле — [src/config.ts](src/config.ts), у каждого есть комментарий на русском.
Поменяйте число, сохраните файл — открытая игра обновится сама.

Чтобы быстро попробовать число, не трогая файл, допишите его к адресу (только при запуске `npm run dev`):
`http://localhost:5173/?qa&cfg=bacteria.startSpeed:150` — бактерии стартуют быстрее.

## Как проверить, что ничего не сломалось

```
npm run qa -- --tag=my-check
```

Команда сама соберёт игру, откроет её в браузере на «телефоне» и «компьютере» (русский и английский),
проверит консоль на ошибки и сложит скриншоты в `qa/screenshots/my-check/`. Перед первым запуском на своём
компьютере выполните `npx playwright install chromium`.

Замер длины партии «виртуальным игроком»: `npm run qa:bot -- --runs=5` (подробности — в CLAUDE.md).
