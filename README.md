# Таблетки против бактерий (Pills vs Bacteria)

Казуальная HTML5-игра для Яндекс Игр в жанре tower defense. Бактерии выходят справа и идут по кривым дорожкам к
организму (красная линия слева). Вы ставите башни-таблетки в свободные клетки рядом с дорожками, и они сами стреляют.
За каждую убитую бактерию — монеты, на них покупаются новые башни. Дошла до организма — минус жизнь; жизни кончились —
проигрыш; все волны отбиты — победа.

> **Статус:** идёт переход на tower defense по этапам. **Этап 1** (слит в `main`): поле, большая карта с камерой, первая башня.
> **Этап 2** (в рабочей ветке): сеть дорожек «как корни» со случайным выбором пути и пять типов бактерий (палочка делает рывки,
> делящаяся распадается на два кокка, спора глушит башни, бронированная отнимает 2 жизни). Правила —
> [docs/td-rules.md](docs/td-rules.md), план — [docs/td-plan.md](docs/td-plan.md).

Полное описание проекта, структура и правила — в [CLAUDE.md](CLAUDE.md).

## Как поиграть

Проще всего — по ссылке из раздела «Игра по постоянной ссылке» ниже: ничего устанавливать не нужно.

Чтобы запустить у себя, нужен установленный [Node.js](https://nodejs.org) (версия 20 или новее). В терминале:

```
git clone https://github.com/Aurinox-eng/1.git
cd 1
npm install
npm run dev
```

Так вы получите ветку `main` — версию, слитую владельцем. Чтобы посмотреть рабочую ветку, которую ведёт агент, добавьте
в первую команду `-b claude/serene-rubin-x3t2gu` (после `git clone`).

Откройте в браузере адрес **http://localhost:5173**. Чтобы поиграть с телефона, подключите его к той же
Wi-Fi сети и откройте адрес `Network:`, который напечатает команда.

Управление (телефон — держите горизонтально):
- справа тап по кнопке башни «Таблетка» (выбранная — с золотой рамкой), затем тап по свободной клетке карты — башня поставлена;
- карту можно двигать пальцем (мышью — перетаскиванием), приближать и отдалять двумя пальцами (щипок) или колесом мыши;
- слева — организм (красная линия): если он за краем экрана, там мигает подсказка «◀ Организм»;
- кнопка справа внизу — пауза.

## Игра по постоянной ссылке (GitHub Pages)

Ссылка: **https://aurinox-eng.github.io/1/** — её можно открыть с любого телефона или компьютера.

Игра выкладывается сама: при каждом обновлении ветки `main` GitHub собирает игру и обновляет ссылку
(1–2 минуты; если на телефоне видна старая версия — обновите страницу). Какая версия сейчас выложена, видно
по адресу https://aurinox-eng.github.io/1/version.txt. Ход сборки — вкладка **Actions** в репозитории.

**Однократная настройка (делается в GitHub, я сделать её не могу):**
1. Репозиторий → **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. GitHub Pages не работает на бесплатном тарифе для закрытых (private) репозиториев. Сейчас репозиторий
   закрытый, поэтому нужно одно из двух: сделать его публичным (Settings → General → Danger Zone → Change
   visibility; станет виден весь код и история) или подключить платный тариф GitHub Pro.
   Сайт на Pages открыт всем, кто знает ссылку, даже если репозиторий закрытый.
3. Готово: настройка сделана, игра по ссылке работает и обновляется при каждом обновлении `main` (то, что в `main`, то и
   играет по ссылке; рабочие ветки `claude/...` не публикуются — их влить в `main` может только владелец через Pull request).
   Пересобрать вручную: Actions → «Опубликовать игру» → Run workflow.

## Как поменять сложность

Все числа баланса лежат в одном файле — [src/config.ts](src/config.ts), у каждого есть комментарий на русском.
Поменяйте число, сохраните файл — открытая игра обновится сама.

Чтобы быстро попробовать число, не трогая файл, допишите его к адресу (только при запуске `npm run dev`):
`http://localhost:5173/?qa&cfg=bacteria.baseSpeed:150` — бактерии идут быстрее.

## Как проверить, что ничего не сломалось

```
npm run qa -- --tag=my-check
```

Команда сама соберёт игру, откроет её в браузере на «телефоне» и «компьютере» (русский и английский),
проверит консоль на ошибки и сложит скриншоты в `qa/screenshots/my-check/`. Перед первым запуском на своём
компьютере выполните `npx playwright install chromium`.

Бот-замерщик баланса под tower defense появится на этапе 3 (старый бот удалён вместе со старой игрой).

В обычной работе проверки запускает помощник-агент (`qa-tester`), а вам в конце этапа приходит одна итоговая таблица —
самому запускать их не нужно.
