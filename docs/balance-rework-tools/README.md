# Средства разбора замеров плана переработки баланса (18 октября 2026)

Python-сценарии читают вложения бота (`results/qa/bot-results/*.json`, поля `games[].timeline` и др.); запускать как `python3 -I <файл> <каталог результатов> [аргументы]`. Файлы лежат без привязки к пути: каталог результатов задаётся аргументом, `wave-table.json` — в текущей папке.

| Файл | Что делает | Аргументы |
|---|---|---|
| `tele.py` | запас силы R по волнам, монеты, башни и действия по волнам для каждого профиля; решения в минуту; самая длинная серия волн без решений | каталог результатов |
| `afk.py` | сколько волн подряд замороженная оборона держит R ≥ 1,7 | каталог результатов, номер уровня |
| `nodec.py` | доля волн без обязательной покупки; режим `new` пересчитывает на вариант А | каталог, номер уровня, `now` или `new` |
| `tables.py` | таблицы п. 2.1 плана (имена каталогов `teleA`, `teleB` вписаны в файл) | — |
| `wave-table.json` | прочность волн и награды уровней 1–6, 10 по `src/config.ts` на `d8e94f8` (для `afk.py`, `nodec.py`) | — |
| `wave-table.ts`, `setup.ts` | сборка `wave-table.json` из данных игры (нужна сборка TypeScript, например `rolldown`; пути внутри файлов — рабочие каталоги сессии, поправить) | — |

Расчёты модели: `docs/balance-rework-model-2026-10-18.mjs` (`node docs/balance-rework-model-2026-10-18.mjs`).
