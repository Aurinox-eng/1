# Технические решения и особенности

Подробности, вынесенные из CLAUDE.md. Описывают код после перехода на tower defense (этап 1). Старая игра с падающими
бактериями — коммит `3b913a3`; её механика и подбор баланса описаны в `docs/balance-history.md` (история).

## Проверки `qa/smoke.mjs` (этап 2: 395 проверок)
- Сценарии: `desktop-ru`, `phone-ru`, `desktop-en`, `phone-en`, `rules`, `graph`, `combat`, `dash`, `split`, `spore`, `armored`,
  `intro`, `lose-ru`/`lose-en`, `win-ru`/`win-en`, `danger`, `rotate`, `production`, `fullgame` (полная партия на 12 волн).
  Запуск: `npm run qa -- --tag=td-1` (весь набор ≈ 15–16 мин; `--only=<имя>` — один сценарий). Скриншоты — `qa/screenshots/td-1/`.
- Запасные переменные: `QA_EXTRA_CFG` (дополнительная подмена чисел, например «ловушки» для проверки самих проверок),
  `QA_FULL_TOWERS` (сколько башен ставит `fullgame`).
- `qa/lib.mjs` **останавливает прогон, если исходники `src` новее `dist-qa`** («сборка устарела»). Поэтому во время прогона
  `src` править нельзя: этап 2 разрабатывался в копии в scratchpad и переносился в проект после завершения прогона.

## Общая инфраструктура
- Экран 1280×720 (16:9), режим масштабирования `Phaser.Scale.FIT`: помещается целиком на любом устройстве, по краям — тёмные поля.
  `base: './'` в `vite.config.ts` — относительные пути обязательны (игра открывается из подпапки `/1/` на Pages и из zip Яндекса).
- Поворот телефона и смена окна: Phaser иногда знает новый размер страницы, но не перестраивает экран
  (воспроизводилось в эмуляции), поэтому `main.ts` сам вызывает пересчёт (`refit`) после `resize`/`orientationchange`.
- Игровое время: `dt = min(deltaMs, 50) / 1000 * TIME_SCALE`. Один кадр не длиннее 50 мс в расчётах движения — после
  сворачивания вкладки объекты не «прыгают»; если кадр длинный, за него может выйти несколько бактерий (не больше 10).
  Всё, что зависит от игрового времени (движение, паузы башен, волны), считается по `dt`; твины и вспышки — по реальному.
- Защита от случайного рестарта после конца уровня (`gameOver.restartLockMs`) и от мгновенного снятия паузы (250 мс) — по
  реальным часам (`performance.now`): игровые часы Phaser отстают, когда кадры тормозят.
- Звуки — свои, `src/sound.ts` (WebAudio, тоны рисуются кодом): аудио создаётся при первом касании/клике — в консоли нет
  предупреждений и звук работает на iPhone. Звуковая система Phaser выключена (`audio.noAudio` в `main.ts`).
  Громкость — `feedback.soundVolume` в `config.ts` (0 — без звука). Есть: выстрел, попадание, уничтожение, башня поставлена,
  «нельзя», новая волна, победа, потеря жизни, проигрыш.
- Язык: `src/lang.ts` берёт язык из браузера; в игровой сборке подмены через адрес нет. На этапе 9 главнее будет язык из SDK Яндекса.
- Иконка вкладки — встроенная SVG в `index.html` (иначе 404 favicon в консоли). `<title>` в `index.html` запасной,
  его заменяет текст из i18n.
- Телефон вертикально: игра горизонтальная, поэтому при `(orientation: portrait) and (pointer: coarse)` поверх неё показывается
  блок `#rotate` из `index.html` («Поверните телефон горизонтально», текст ставит `main.ts` из i18n), а игровое время и жесты
  стоят (`src/orientation.ts`). На компьютере с мышью этого нет. Требования Яндекс Игр к ориентации не проверены (этап 9).
- Текст рисуется с `resolution: 2` (чёткий при масштабировании экрана и приближении карты).
- В окружении агента `node_modules` может быть пустой: `PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1 npm install` (браузер уже лежит в
  `/opt/pw-browsers`).

## Две сборки и режим проверки (?qa)
- `npm run build` → `dist/` — ИГРОВАЯ; `npm run build:qa` → `dist-qa/` — ТЕСТОВАЯ.
- `QA_ENABLED = import.meta.env.DEV || MODE === 'qa'`. В игровую сборку код `?qa` не попадает вообще; проверка
  `qa/smoke.mjs` убеждается, что в ней нет `?qa`, подмены `?cfg=` и `?lang=`. Это важно для этапа 9: иначе рекорд и рекламу
  можно накрутить из адресной строки.
- Возможности `?qa`: `window.__pvb` — `getState()` (снимок состояния, `DebugSnapshot` в `src/debug.ts`: монеты, жизни, волна,
  башни, бактерии, камера, положение кнопок панели, счётчики откликов), `worldToClient / gameToClient / cellToClient`
  (перевод координат мира/игры/клетки в координаты страницы — для мыши и касаний Playwright), `speed=N` (ускорение времени),
  `cfg=раздел.параметр:число` (подмена числа из `config.ts`, вложенные пути через точки), `lang=en`.
- Проверки запускает субагент `qa-tester` (`npm run qa -- --tag=<имя>`); скрипт стирает папку `qa/screenshots/<имя>` перед
  прогоном. Не использовать теги `stage-1`, `stage-1b` (там скриншоты старой игры) и `td-1-mockup` (макет).

## Как устроена игра сейчас (этапы 1–2)
- **Карта** 18×14 клеток по 103 px + зона организма 150 px слева (мир 2004×1442 px). Рисуется один раз обычным canvas в четыре
  текстуры (`src/mapArt.ts`; куски не больше 2048 px — безопасно для старых телефонов; плотность = максимальное приближение,
  поэтому карта чёткая). При перезапуске уровня текстуры используются повторно.
- **Данные уровня** — `src/level.ts`: размер карты, **граф дорожек** (узлы и рёбра, «корневая система»: 3 входа, 3 выхода, 4 развилки,
  5 слияний), стартовая точка камеры. `src/pathing.ts` строит каждое ребро как плавную кривую Безье с горизонтальными касательными на
  концах (поэтому рёбра в узлах стыкуются гладко): по ней и рисуется дорожка, и ходят бактерии (позиция = точка на расстоянии `s` от
  начала ребра). В конце ребра бактерия выбирает следующее **случайно и поровну** среди рёбер, выходящих из узла (развилка).
  `remainingAtEnd` ребра — сколько пикселей до организма по самому короткому пути: по нему башни выбирают «ближайшую к организму».
  Клетки, задетые дорожкой (центр ближе полуширины дорожки + 0,45 клетки), — `PATH_TILES`, ставить башни там нельзя: 94 клетки из 252, свободных 158; запас нужен, чтобы основание башни не заходило на полосу дорожки.
- **Камера** — `src/cameraRig.ts`: не камера Phaser, а масштабирование и сдвиг контейнера с миром; панель справа лежит поверх и
  не двигается (окно карты 1080×720). Карта не выезжает за край; минимальное приближение (0.54) — по ширине карта помещается целиком.
- **Жесты** — `src/mapGestures.ts`: один палец/мышь — сдвиг, два пальца — щипок и сдвиг, колесо — приближение вокруг курсора
  (учитывает `deltaMode`: Firefox шлёт строки, а не пиксели), касание без сдвига (≤ `tapMaxMovePx` = 22 px экрана игры ≈ 12 px на
  стекле телефона 844×390, ≤ `tapMaxMs`) — тап. Когда палец выходит за порог, карта сразу догоняет его. Тапом не считается:
  жест с двумя пальцами, касание, отменённое системой (`wasCanceled`), палец, отпущенный над правой панелью. Касания правой
  панели в жесты не попадают: её кнопки — интерактивные зоны Phaser.
- **Башни** — таблица `CONFIG.towers` (цена, радиус, урон, пауза, скорость снаряда, способ стрельбы `targeting`). Сейчас один
  способ — `radius`: из бактерий в радиусе выбирается та, что дальше всех прошла по дорожке. Снаряд летит за целью; если цель
  уже уничтожена другим выстрелом, долетает до последнего её места и исчезает.
- **Волны** — `CONFIG.waves`: первая через `firstDelaySec`, между волнами `pauseSec`, пауза между выходом бактерий сокращается от
  `intervalStartSec` до `intervalEndSec`. **Состав** волн — таблица `waves.list` (сколько бактерий каждого типа); типы выходят в
  случайном порядке, а тип, которого ещё не было, — первым и один (сигнал `sfx.newType` и сообщение сверху). Вышли все и на карте
  никого — победа. Число волн — `waves.total` (не больше строк списка).
- **Особенности типов** (колонки таблицы `CONFIG.types`): палочка — **рывки** (`dash*`: раз в `dashEverySec` секунд на `dashSec` секунд
  скорость ×`dashFactor`, у каждой палочки свой сдвиг часов); делящаяся — при гибели **кокки** (`splitCount` штук на расстоянии
  `splitGapPx` вдоль дорожки на том же ребре); спора — **глушит башни** (`disableSec`, `disableRadius`: башня темнеет, не стреляет;
  каждую башню одна спора глушит один раз); бронированная — прочная, 2 жизни, без особых свойств.
- **Панель** — `src/ui/Panel.ts`: волна и прогресс, монеты, жизни (сердца), кнопка «Таблетка» и три закрытые, пауза, подсказка
  «◀ Организм» у левого края (когда организм за краем экрана; мигает красным, если бактерия ближе `ui.dangerDistancePx`),
  всплывающие сообщения сверху и постоянная подсказка снизу.
- **Отклик** — `src/effects.ts`: вспышка при попадании, частицы и «+монеты» при уничтожении, кольцо при постановке башни;
  при потере жизни — красная вспышка на ВСЁМ экране и тряска (организм может быть за краем экрана).
- Бактерии рисует `bacteriumArt.ts` (форма, толщина оболочки и трещины зависят от типа и оставшегося HP).
- Башню можно поставить при любом приближении (решение владельца); при сильном отдалении клетка на телефоне мельче пальца.

## Особенности рабочей среды (для агента)
- Облачный контейнер ≈ 4 ядра, программный WebGL (~14 fps). Он может перезапуститься и убить фоновые задачи; долгие замеры лучше
  запускать так, чтобы потерю не жалко.
- Определения субагентов подхватываются только при старте сессии — в текущей сессии инструкции давать в самом промпте.
- Write/Edit требуют предварительного Read файла (после `git checkout`/`cp` — «file modified since read»; обход: heredoc/python).
- `pkill -f` использовать с шаблоном `[q]a/smoke.mjs`, иначе убьёшь собственную команду.
- Инструменты GitHub (`mcp__github__*`) подгружаются через ToolSearch; `gh` в облаке нет. Отправка меток (tags) на GitHub из
  облака не проходит (403).
- Chromium для Playwright лежит в `/opt/pw-browsers`; `qa/lib.mjs` умеет его искать.
- После слияния PR ветка `claude/...` уже «старая»: `git fetch origin main && git rebase origin/main`, затем
  `git push --force-with-lease` (это своя рабочая ветка, не чужая). Новый PR — только по просьбе владельца.
- GitHub Pages кэширует страницу до 10 минут (`max-age=600`): владелец может видеть старую версию после слияния. Проверять
  сервер: `version.txt` рядом с игрой и имя файла бандла.
- Автоматический хук «есть незакоммиченные изменения» требует коммитить и пушить; для промежуточных состояний — коммит
  «Промежуточная точка (WIP)», потом нормальный коммит.
- В файлы с `&&`-цепочкой `git add` не подставлять удалённые пути: команда упадёт, и коммит не сделается.
- Дубли ключей в `src/i18n.ts` после массовой замены: проверять `npm run typecheck` (ключ в `ru` без `en` не соберётся).
