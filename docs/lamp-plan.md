# Лампа: детектор вместо основной башни (план принят владельцем 12 октября 2026: «оставить, на паузу не ставить»)

## Решение владельца (12 октября)
Лампу ограничивать. Критерий: одиночная башня не выигрывает уровень. Сейчас одна Лампа + Сироп выигрывает уровни 5, 6 и 10 (6 партий из 6, профиль `expert`, `docs/balance-history.md`, «Пересмотр»). Направление: Лампа — прежде всего детектор (подсвечивает скрытных в радиусе, по ним бьют остальные башни), собственный урон слабый. Цель: одна Лампа + Сироп проигрывает; смешанный набор с 1–3 Лампами — лучший вариант.

## Что меняется
1. **Подсветка.** Новая колонка таблицы башен `lightSec` (у Лампы 1,5 с, у остальных 0). Лампа подсвечивает каждую скрытную бактерию в круге радиуса `range` (200 px, а не только в конусе) и держит её подсвеченной ещё `lightSec` секунд после выхода из круга. Подсвеченную скрытную остальные башни видят на полном радиусе, а не на 0,6 радиуса (`Tower.candidates`: `reach = range`, если бактерия подсвечена). Несколько Ламп не складываются: бактерия либо подсвечена, либо нет.
2. **Собственный урон.** `towers.lamp.damage` с 1,4 до X за тик (раз в 100 мс); сейчас 14 урона в секунду каждой бактерии в конусе, у Таблетки — 1. Конус, цена 200, улучшения ветки Лампы не меняются. X подбирается замером (ниже), первое предположение — 0,2 (2 урона в секунду).
3. **Тексты** (`src/i18n.ts`, русский и английский): карточка и альманах Лампы («подсвечивает скрытных в радиусе — тогда их видят все башни»), плашка скрытной бактерии, строка в альманахе скрытной.
4. **Бот** (`qa/bot.mjs`, `--lamps`): не больше 3 Ламп (сейчас одна на две Таблетки); сама подсветка бота не касается.

## Как подбираю X (до изменения кода, одним прогоном через `--cfg`)
Одна Лампа + Сироп, `expert`, уровни 5, 6, 10, по 6 партий, `towers.lamp.damage` = 0,2 / 0,3 / 0,45 / 0,7 (варианты через «;» в одном запросе). **Выбирается наибольшее X, при котором у одной Лампы + Сироп 0 побед из 6 на всех трёх уровнях** (сильнее Лампа остаётся, не выигрывая уровень в одиночку). Если не выигрывает и 0,7 — сетка продлевается вверх (1,0 и далее); если выигрывает и 0,2 — вниз (0,1). Пробная партия — первой: один вариант (0,45), уровень 5, одна партия.

## Броня и урон Лампы (выбор)
Броня вычитается из каждого тика (раз в 100 мс) отдельно: `Bacterium.hit`: `dealt = max(raw × combat.armorMinShare, raw − armor)`, `armorMinShare` = 0,25. Урон по бронированным **не нулевой**: при `X ≤ броня` каждый тик наносит 25 % от X (бронированная, броня 2: при X = 0,45 — 0,11 за тик, 1,1 урона в секунду; гигант, броня 1: то же при X ≤ 1,33). То есть Лампа против брони слабее в 4 раза, как и любая другая башня с малым ударом (Таблетка, 1 урона: по броне 2 наносит 0,25). **Выбираю не менять правило брони для Лампы** (это общее правило для всех ударов башен; Лампа как детектор не должна быть ещё и средством против брони). Если замер покажет, что при выбранном X смешанный набор с Лампами не побеждает бронированных хуже, чем без них, правило остаётся; иначе — отдельный пункт плана с вашим решением.

## Критерии приёмки после изменения
| Проверка | Требование |
|---|---|
| Одна Лампа + Сироп, уровни 5, 6, 10, `expert` и `strong` | 0 побед из 6 |
| Смешанный набор с 1–3 Лампами (`--lamps`, потолок 3) против смешанного без Ламп (18 / 18 / 20) | медиана волны выше на всех трёх уровнях |
| Смешанный с Лампами против одной Лампы | выше на всех трёх уровнях |
| Остальные башни | числа не менялись |

Риски: подсветка действует только рядом с Лампой, поэтому Лампу придётся ставить у башен, а не у входа; если X найдено слишком малым, Лампа перестанет быть полезной и смешанный набор с Лампами не обгонит смешанный без них — тогда поднимаю X или `lightSec`.

## Состояние (12 октября 2026)
- Механика в коде: колонка `lightSec` (`src/config.ts`, `src/towerStats.ts`), `Bacterium.light()/lit`, `GameScene.applyLamps()` (подсвечивает скрытных в круге `range` работающей Лампы), `Tower.candidates()` (подсвеченную видят на полном радиусе), подсвеченная скрытная непрозрачна; тексты карточки, альманаха и плашки; `lit` в снимке игры и проверка в `qa/smoke.mjs` («Лампа подсвечивает скрытную»); потолок 3 «обычных» Лампы у бота в `--lamps` (`LAMP_MAX_STEALTH`).
- Урон Лампы подставлен по сетке: `towers.lamp.damage` = 0,1 (наибольшее X с 0 побед из 6 на уровнях 5, 6, 10, `expert`).
- Приёмка на `1e8bb32` (6 прогонов, `docs/balance-history.md`, «Приёмка Лампы-детектора»): **критерий 1 выполнен** (одна Лампа + Сироп — 0 побед из 36 партий); **критерий 2 не выполнен** (смешанный набор с Лампами не выше смешанного без Ламп: `expert` 17–18 / 17–18 / 20 против 18 / 18 / 20). Причины: стена 17–20-й волны шире скрытных (держится и при выключенных скрытных), а бот копит монеты на Лампу и строит её поздно. Скрытные среди убийц `expert` теперь в 3 партиях из 18 (было 3 из 5 потерь).
- Предложение по критерию 2 (решает владелец): заменить «волна выше» на «доля потерь жизней от скрытных ниже, чем без Ламп; волна не хуже»; правило покупок бота — Лампа вне очереди только за три волны до выхода скрытных (на уровне 5 — с 12-й), до этого монеты идут в Таблетки.
