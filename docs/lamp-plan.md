# Лампа: детектор вместо основной башни (план, ждёт «ок» владельца; 12 октября 2026)

## Решение владельца (12 октября)
Лампу ограничивать. Критерий: одиночная башня не выигрывает уровень. Сейчас одна Лампа + Сироп выигрывает уровни 5, 6 и 10 (6 партий из 6, профиль `expert`, `docs/balance-history.md`, «Пересмотр»). Направление: Лампа — прежде всего детектор (подсвечивает скрытных в радиусе, по ним бьют остальные башни), собственный урон слабый. Цель: одна Лампа + Сироп проигрывает; смешанный набор с 1–3 Лампами — лучший вариант.

## Что меняется
1. **Подсветка.** Новая колонка таблицы башен `lightSec` (у Лампы 1,5 с, у остальных 0). Лампа подсвечивает каждую скрытную бактерию в круге радиуса `range` (200 px, а не только в конусе) и держит её подсвеченной ещё `lightSec` секунд после выхода из круга. Подсвеченную скрытную остальные башни видят на полном радиусе, а не на 0,6 радиуса (`Tower.candidates`: `reach = range`, если бактерия подсвечена). Несколько Ламп не складываются: подсвеченная и подсвеченная — одно и то же.
2. **Собственный урон.** `towers.lamp.damage` с 1,4 до X за тик (раз в 100 мс); сейчас 14 урона в секунду каждой бактерии в конусе, у Таблетки — 1. Конус, цена 200, улучшения ветки Лампы не меняются. X подбирается замером (ниже), первое предположение — 0,2 (2 урона в секунду).
3. **Тексты** (`src/i18n.ts`, русский и английский): карточка и альманах Лампы («подсвечивает скрытных в радиусе — тогда их видят все башни»), плашка скрытной бактерии, строка в альманахе скрытной.
4. **Бот** (`qa/bot.mjs`, `--lamps`): не больше 3 Ламп (сейчас одна на две Таблетки); сама подсветка бота не касается.

## Как подбираю X (до изменения кода, одним прогоном через `--cfg`)
Одна Лампа + Сироп, `expert`, уровни 5, 6, 10, по 6 партий, `towers.lamp.damage` = 0,2 / 0,3 / 0,45 / 0,7 (варианты через «;» в одном запросе). Подходит наименьшее X, при котором побед 0 из 6 на всех трёх уровнях. Пробная партия — первой.

## Критерии приёмки после изменения
| Проверка | Требование |
|---|---|
| Одна Лампа + Сироп, уровни 5, 6, 10, `expert` и `strong` | 0 побед из 6 |
| Смешанный набор с 1–3 Лампами (`--lamps`, потолок 3) против смешанного без Ламп (18 / 18 / 20) | медиана волны выше на всех трёх уровнях |
| Смешанный с Лампами против одной Лампы | выше на всех трёх уровнях |
| Остальные башни | числа не менялись |

Риски: подсветка действует только рядом с Лампой, поэтому Лампу придётся ставить у башен, а не у входа; если X найдено слишком малым, Лампа перестанет быть полезной и смешанный набор с Лампами не обгонит смешанный без них — тогда поднимаю X или `lightSec`.
