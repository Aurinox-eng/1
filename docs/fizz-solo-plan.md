# Шипучка: ограничение по площади и замер «одна башня» (план, «ок» владельца 11 октября 2026)

## Причина
Оценка со стороны (уровень 5, набор «первая партия» из `qa/ladder-sets.mjs`): одинаковый скрипт, только Таблетки + 1 Сироп — проигрыш на 21-й волне,
только Шипучки + 1 Сироп — на 27-й. Владелец: 8 Шипучек хватает на любой уровень. Взрыв Шипучки бил всех в круге полным уроном без предела.

## Правило (принято)
- `towers.fizz.blastFullTargets` = 5 целей получают полный урон, остальные цели круга — `blastRestMul` = ×0,35 (числа для начала; окончательно подбирает бот).
- Цели — по расстоянию от центра взрыва, ближайшие первыми. Цепной взрыв (радиус ×0,7, урон ×0,6) ограничен так же, отдельно для каждого взрыва.
- «Кислота» (`fizzAcid`) — только целям с полным уроном (первым N); остальным её взрыв не даёт. Кислота по-прежнему не складывается.
- Радиус (улучшение `fizzBlast`, мутация `fizzBig` «Большая») число целей с полным уроном не добавляет.
- Строка в карточке башни и в альманахе (ru и en), числа берутся из `config.ts`.

## Замер: «одна башня» против смешанного набора (принято с правками владельца)
1. Сравнивать там, где смешанный набор сам проигрывает: уровень открытия башни и уровень 10, прочность бактерий повышена (как в лестнице; подмена
   `--cfg levels.specs.<N−1>.growth.latePerWave:<число>`), медиана волны гибели смешанного набора около 22–26. Цель: одиночная башня гибнет минимум на 3 волны раньше,
   побед у одиночной нет.
2. Набор улучшений для `--solo`: те же очки ДНК, что в `ladder-sets`, но в первую очередь в ветку этой башни (игрок, играющий Шипучками, качает Шипучку).
   Эталонный набор уровня 5 веткой Шипучки не тронут — он занижает именно её.
3. Уровни: каждую башню на уровне её открытия и на уровне 10 (`towerUnlock`: Таблетка 1, Ампула 3, Шипучка 5, Лампа 5, Антибиотик 6, Витамин 7, Холод 8, Пластырь 9,
   Шприц 10 — Шприц только на 10).
4. Урон-башни (Таблетка, Шипучка, Шприц, Ампула, Антибиотик, Лампа): «башня + 1 Сироп». Витамин, Холод, Пластырь: «башня + 1 Сироп + Таблетки»,
   база для сравнения — «только Таблетки + 1 Сироп» (`--solo=pill`).
5. Партий: 6 для первой прикидки, 10 для итоговых чисел.
