«Любые две одинаковые»). Этап 4 раньше был пропущен («Улучшения в партии»), теперь возвращается — вместе со слиянием; после него — этап 5 (меню, 10 уровней).

## Зачем (проще говоря)
Клеток для башен мало (115), а к 30-й волне денег хватает на ≈ 50 башен. Слияние даёт, куда девать деньги и места: вместо 8 слабых башен — одна сильная. Улучшения-«мутации»
дают выбор: каждая башня может вырасти в одну из нескольких «профессий». Игроки с одним и тем же набором башен играют по-разному.

## Правила слияния
- Сливаются **две башни одного вида и одного уровня** (в любых клетках карты). Результат — одна башня уровня +1 **в клетке, по которой тапнули вторым**; первая исчезает, её клетка свободна.
- Уровней **4** (то есть 1 башня ур. 4 = 8 обычных). Слияние **бесплатное**.
- Что остаётся: направление луча у Шприца берётся у той башни, куда сливали; выбранные мутации сохраняются, если башни одного уровня и у них одинаковый выбор (иначе — мутации сбрасываются, предупреждение перед слиянием).
- Спора, заглушившая башню, глушит и результат слияния только на оставшиеся секунды.

## Сила уровней (первое приближение; числа в таблице `towerLevels` в config.ts, подбирает бот)
Общий множитель на уровень, потом подгоняется для каждой башни отдельно. Замысел: уровень чуть сильнее, чем две башни прошлого уровня (бонус ≈ 10 %), и ещё экономит клетку.

| Уровень | Урон (у Сиропа: радиус и время лужи; у Шипучки: ещё радиус взрыва) | Скорострельность | Радиус |
|---|---|---|---|
| 1 | ×1 | ×1 | ×1 |
| 2 | ×1,9 | +5 % | +4 % |
| 3 | ×3,6 | +10 % | +8 % |
| 4 | ×6,4 | +15 % | +12 % |

(Первое приближение было ×2,2 / ×4,8 / ×10,5, пауза −9/−17/−23 %, радиус +5/+10/+15 % — владелец после PR #12 попросил слабее: см. `docs/decisions.md`.)
Шприц: радиуса нет — вместо него +1 удар в очереди на уровне 4.

## «Мутации» — улучшения в глубину
На уровнях **2 и 4** башня получает выбор одной из двух мутаций (бесплатно, один раз на каждый порог, потом не изменить). Вид башни × порог × 2 варианта = 16 мутаций, данные в таблице `mutations`.
Первая очередь — только числовые (не требуют нового кода); «особые» (отмечены ★) — с новым поведением, во второй очереди.

| Башня | Уровень 2: выбор | Уровень 4: выбор |
|---|---|---|
| Таблетка | «Скорострел» (пауза −35 %) / «Бронебойная» (игнорирует броню) | «Двойной выстрел» ★ (бьёт две цели) / «Охотник» (+100 % урона по самой прочной цели) |
| Сироп | «Липкая» (замедление сильнее, ×0,25) / «Большая лужа» (радиус +60 %) | «Едкая» ★ (лужа наносит урон 1/с) / «Две капли» ★ (два выстрела за раз) |
| Шипучка | «Большой взрыв» (радиус ×1,5) / «Быстрая» (пауза −35 %) | «Цепная» ★ (после взрыва — второй, поменьше) / «Кислота» ★ (задетые получают +50 % урона 3 с) |
| Шприц | «Больше ударов» (+2 в очереди) / «Бронебойный» (урон ×1,5, игнорирует броню) | «Второй луч» ★ (под 90° к первому) / «Спираль» (каждый удар очереди сильнее на +1) |

## Управление (предложение, ждёт «ок»)
- **Тап по поставленной башне** выбирает её (золотое кольцо) и открывает карточку у края экрана: название, уровень, числа; кнопки **«Слить»** (включает режим: светятся все башни, с которыми можно слить; тап по любой — слияние; тап мимо — отмена),
  **мутации** (если порог достигнут) и **«Продать»** (возвращает 70 % цены, `economy.sellRefund`).
- **Шприц:** тап по башне выбирает её; на выбранном Шприце тап по правой/левой половине поворачивает луч на 45° вправо/влево (как сейчас, но после выбора; в карточке то же — две кнопки со стрелками). Сейчас поворот работает с первого тапа —
  придётся сделать на один тап дольше, иначе нечем открыть карточку.
- Без выбранной башни на панели справа тап по пустой клетке ничего не ставит (как сейчас).

- **Слияние:** тап по башне выбирает её (золотое кольцо, у башен без луча — круг радиуса); в карточке справа кнопка «Слить» подсвечивает зелёным все башни того же вида и уровня; тап по любой — слияние

- **Продажа:** кнопка «Продать» возвращает 70 % цены × 2^(уровень−1). Карточка закрывается крестиком или тапом по пустой клетке.

  (в плане было «+100 % по самой прочной»); (3) повернуть луч Шприца теперь так: тап по башне выбирает её, дальше — стрелки в карточке или тап по правой/левой половине уже выбранной башни;
