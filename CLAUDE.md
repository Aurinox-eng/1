# Таблетки против бактерий (Pills vs Bacteria)

Казуальная HTML5-игра для публикации на **Яндекс Играх**. Владелец проекта — не программист: технические решения
принимаются самостоятельно и коротко объясняются простыми словами (по-русски), без жаргона.

## Технологии
Phaser 3.90 (третья версия! не обновлять до 4) + TypeScript + Vite. Графика рисуется кодом, звуки — синтезом (WebAudio),
внешних картинок и звуковых файлов нет, пока владелец не скажет иначе. Тексты — русский и английский.

## Текущая механика (пока не заменена)
Бактерии опускаются сверху, игрок тапом/кликом стреляет таблеткой снизу вверх (1 таблетка = 1 HP), 3 жизни: бактерия,
дошедшая до красной линии, исчезает и отнимает жизнь (бронированная — две). Пять типов — таблица `types` в `src/config.ts`:
кокк (1 HP, медленный), палочка (2 HP, зигзаг), делящаяся (2 HP; при гибели — два кокка, сама делится через 6 с без попаданий),
бронированная (6 HP, медленная, 2 жизни), спора (1 HP, быстрая, с 60-й секунды). Типы вводятся по одному каждые ~15 с.
Подробности реализации — `docs/technical-notes.md`.

## Команды
| Команда | Что делает |
|---|---|
| `npm install` | установить зависимости (один раз) |
| `npm run dev` | игра для разработки: http://localhost:5173 (с телефона в той же Wi-Fi — адрес `Network:`) |
| `npm run build` | проверка типов + ИГРОВАЯ сборка в `dist/` (уйдёт на Яндекс; режима `?qa` в ней нет) |
| `npm run build:qa` | ТЕСТОВАЯ сборка в `dist-qa/` (с режимом `?qa`; в неё играют проверки и бот) |
| `npm run preview` | посмотреть собранную игровую версию |
| `npm run typecheck` | только проверка типов |
| `npm run qa -- --tag=<этап>` | обе сборки + проверка в браузере (телефон/компьютер, RU/EN, поворот, два пальца), скриншоты в `qa/screenshots/<этап>/`; ~2–3 мин; `--only=phone-ru` — один сценарий |
| `npm run qa:bot -- --runs=5 --speed=2 --tps=3 --error=25 --reaction=0.3` | бот играет и замеряет длину партии; `--profile=random6\|random3\|average\|strong`, `--all` — все профили; `--shots=10,30,60 --tag=<имя>` — скриншоты |

Нужен Chromium: в облаке уже есть; у себя — один раз `npx playwright install chromium`.
**Боты — по одному, `--speed` не выше 2** (иначе замер искажается). Бот написан под текущую механику.

## Правила проекта (обязательно)
1. **План → одобрение → код.** Крупные решения сначала согласуются с владельцем.
2. **Баланс — только в `src/config.ts`** (скорости, частоты, очки, паузы), комментарии на русском, с единицами измерения.
3. **Тексты — на русском и английском** в `src/i18n.ts` (без перевода проект не соберётся); строк-надписей в коде сцен нет.
4. **Графика рисуется кодом**, без внешних картинок.
5. **Конец каждого этапа:** сборка → прогон `qa-tester` → скриншоты → команда, по которой владелец сам поиграет; затем коммит
   и push в `claude/pills-bacteria-game-plan-1frwn6`. **Pull request — только по просьбе владельца.**
6. Владелец следит из приложения Claude: файлы для него класть внутри проекта (скриншоты — в `qa/screenshots/`).

## Субагенты (`.claude/agents/`)
- **game-designer** — предлагает и настраивает баланс, правит только `src/config.ts` и `docs/`, проверяет ботом. Его цели
  (шаг 1б) написаны под падающие бактерии и **устареют** при смене жанра.
- **qa-tester** — запускает игру в браузере (Playwright), проверяет консоль, делает скриншоты, код не правит.
- Определения агентов подхватываются только при старте сессии.

## Публикация (GitHub Pages)
При каждом обновлении `main` workflow `pages.yml` собирает игровую версию (`npm ci` → `npm run build`; упала сборка — ничего не
публикуется) и выкладывает `dist/` на https://aurinox-eng.github.io/1/ (+ `version.txt` с коммитом и временем). Это для пробной
игры; на Яндекс Игры игра уходит zip-архивом (этап 5). Однократные настройки Pages — в README.md. Ветка `claude/...` не публикуется.

## Режим проверки (?qa)
`/?qa&speed=4&cfg=bacteria.startSpeed:120&lang=en` — открывает состояние игры для тестов, ускоряет время, подменяет числа
`config.ts`. Работает **только** при `npm run dev` и в тестовой сборке; в игровую не попадает (проверка `qa/smoke.mjs`).
Важно для этапа 4: иначе рекорд и рекламу можно накрутить из адресной строки. Подробности — `docs/technical-notes.md`.
